# OAMAZONES AI

## Sistema Inteligente de Automação Editorial

O OAMAZONES AI é uma plataforma desenvolvida para automatizar a produção e distribuição de conteúdo do Portal Oamazones.

### Objetivos

- Gerar conteúdo para Instagram automaticamente
- Gerar Stories
- Gerar Reels
- Gerar texto para WhatsApp
- Gerar Facebook
- Gerar SEO
- Gerar Google Discover
- Publicação automática
- Dashboard de monitoramento
